# Sweets-Factory-Sales-Analysis
This project focuses on analyzing the sales and returns data for a central sweets factory that supplies 61 retail stores. The primary goal was to investigate the reasons behind $1.6M in returns and identify operational risks within the supply chain.

🛠 Tools Used
Advanced Excel: For data modeling and final dashboarding.

Power Query (ETL): Used for cleaning, transforming, and structuring raw data from multiple sources.

DAX & Pivot Tables: To create complex measures and dynamic reporting.

📊 Key Business Insights
Revenue Concentration Risk: Discovered that only 10 stores (16% of the client base) generate 51% of the total revenue, highlighting a high dependency on a few key accounts.

Returns Root Cause: Conducted a deep dive into the $1.6M losses, categorizing them into:

Product Defects: Specific items like Cupcakes and Cheesecake had the highest return rates.

Operational Failures: Identified significant losses due to poor handling and delivery errors by specific staff members.

Performance Benchmarking: Analyzed salesperson efficiency to correlate delivery errors with specific routes.

📂 Project Structure
Analysis_Report.pdf: The final presentation with visualized insights.

Factory_Data_Model.xlsx: The raw data, Power Query steps, and interactive dashboard.

Images/: Screenshots of the dashboard and key charts.

🚀 Key Recommendations
Staff Training: Implement specialized handling training for the delivery team associated with high return rates.

Quality Control: Review the production line for top-returned items (Cupcakes/Cheesecakes).

Client Diversification: Develop a strategy to reduce the concentration risk by growing smaller accounts.
